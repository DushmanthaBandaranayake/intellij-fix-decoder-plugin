Reports FIX messages whose repeating groups are broken:
  • the NumInGroup count does not match the number of instances found
  • an instance does not start with the group's first field (its delimiter)
  • a field is out of order, or appears twice, inside an instance
  • an unknown tag ends a group early (add it to a custom dictionary if it belongs to the group)

The quick fix sets the count to the number of instances present.

Can be switched off in Settings | Tools | FIX Decoder.
